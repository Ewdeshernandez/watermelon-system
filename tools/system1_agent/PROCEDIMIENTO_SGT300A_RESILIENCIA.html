2. ⚠️ Causa raíz del “tras reiniciar no exporta” — NO era el teclado

El culpable: “Shutdown Event Tracker” de Windows Server
Tras un apagado/reinicio inesperado (incl. Restart-Computer -Force), Server 2022 saca el modal “Why did the computer shut down unexpectedly?”. Ese cuadro roba el foco → cuando el robot teclea el nombre del “Save As”, el texto cae en SU caja (se veía Problem Id: C:\WM_wave\csv\1yd.csv) → el “Save As” queda vacío → #32770 no apareció → el 1.er canal falla → cascada no hallé 'Export to CSV' → 0/8. Solo ocurría tras reiniciar; a mano después (ya sin el cuadro) daba 8/8. Por eso parecía “problema de teclado”.

3. Procedimiento en la VM (System1) — exporta

Desactivar el Shutdown Event Tracker (fix permanente de la causa raíz)

En PowerShell como Administrator:

reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows NT\Reliability" /v ShutdownReasonOn /t REG_DWORD /d 0 /f
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows NT\Reliability" /v ShutdownReasonUI /t REG_DWORD /d 0 /f

Descargar / actualizar el robot (la VM no tiene git)

El repo es público; se baja el archivo del raw de GitHub:

Invoke-WebRequest -Uri "https://raw.githubusercontent.com/Ewdeshernandez/watermelon-system/main/tools/system1_agent/s1_rpa_export.py" -OutFile "C:\Watermelon\agent\s1_rpa_export.py"

El robot ya trae: --nav, reintento de canales (3 pasadas), reintento de right-click con offsets (tiles al borde como 6xd), cierre del Shutdown Event Tracker en _dismiss_dialogs, y forzado de teclado en-US por-ventana en el Save As.

6. Troubleshooting / notas finas

SíntomaCausa / arreglo
Tras reiniciar no exporta (Save As vacío) Shutdown Event Tracker roba foco → desactivar por registro (§3.1). El robot también lo cierra solo.
Save As teclea mal (\→}, :→ñ) Guest revierte a Latin American. El robot fuerza en-US por-ventana (WM_INPUTLANGCHANGEREQUEST) antes de teclear.
“Save As” se congela con _ en la ruta El underscore es inteclable en el RDP anidado → usar csvgb, NO csv_gb.
Un tile da no hallé 'Export to CSV' (p.ej. 6xd) Right-click cae al borde del plot → el robot reintenta con offsets (±12/−18).
Web no muestra capturas nuevas (de tarde) Supabase .list() devuelve solo 100 ascendente → list_captures pide limit alto + sortBy desc.
Máquina en línea pero 0 rpm Estado “Máquina detenida” (RPM<100). El reporte muestra datos actuales; IA+RAG se apagan (texto honesto).
